## Origen académico

El proyecto parte del caso ficticio **Easy Loans**, utilizado como base de una tarea final del módulo *Business Intelligence con Tableau*.

La versión de portfolio ha sido posteriormente revisada, rediseñada y optimizada para su presentación profesional.

## Datos

El archivo fuente original `Easy Loans Operaciones 2023.xlsx` fue proporcionado en el contexto académico.

**El dataset original no se incluye ni se redistribuye en este repositorio.**

Quien desee reproducir el ejercicio original deberá obtener los materiales a través de la fuente autorizada correspondiente y respetar sus condiciones de uso.

## Workbook de Tableau

El workbook empaquetado de Tableau que contiene el extracto de datos tampoco se distribuye en este repositorio.

La versión interactiva del proyecto está disponible mediante Tableau Public.
